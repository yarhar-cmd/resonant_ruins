# Shadow mode

Shadow scoring has zero gameplay authority in `mvp-0.5`. Generator-4 first constructs and validates
the immutable shared candidate pool, the active Rules or Neutral selector finalizes its decision,
and only then an optional observer receives feature snapshots. Observer success, incompatibility,
or failure cannot alter selection, ordering seen by the active selector, RNG consumption, geometry,
Rats, Runes, Fountains, exits, condition, profile, or feedback.

Shadow scoring is eligible only in Pilot and Official Research on compatible generator-4 rooms. No
approved artifact is installed, so Official runs currently store no fake evidence. A local/Preview
Model Lab user may explicitly select the synthetic fixture for Pilot testing; the selection is
memory-only and clears on reload. Normal gameplay, authored rooms, ordinary Topology Lab generation,
and incompatible saved generators never score.

Optional `shadow-1` evidence stores compact model/artifact identity, pool and active decision,
candidate probabilities/ranks, agreement, top contributions, prior-rating availability, timing,
sanitized failure data, and the observed rating only after feedback. Predictions are not displayed
before feedback. Invalid optional shadow state is discarded without destroying the research
session, and refresh-safe pending state preserves exactly-once room records.
